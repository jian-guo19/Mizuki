录了三个小时，剪的时候才发现系统音量盖过了人声。那一段恰好是最精彩的一场团战，戴耳机听只能听见技能音效。

我试过降噪、试过把人声拉满，最后得到的是一段混着电流声的嘶吼。那天晚上我把素材删了，第二天重录。

这件事让我明白：游戏剪辑里最贵的错误，全发生在录制阶段，而代价要到剪辑阶段才结算。

这篇是本站第一篇正式内容，把整条链路从头到尾走一遍。录制、素材、剪辑、导出、分发，五个环节各有一个坑，踩过的人和没踩过的人，看这篇的收获完全不同。

## 录制：地基打歪了，后面全是补丁

录屏最怕「录的时候没感觉，剪的时候想重来」。标准在录制阶段就定死，能省掉后面一大半返工。

### OBS 关键设置

| 设置项 | 建议值 | 说明 |
| :--- | :--- | :--- |
| 编码器 | NVENC / QSV / Apple 硬件编码 | 有独显优先用硬件编码，几乎不占 CPU |
| 视频格式 | MKV | 崩溃也不丢文件，剪前再转 MP4 |
| 基础分辨率 | 与显示器一致 | 避免强行缩放导致模糊 |
| 输出分辨率 | 1080p | 大多数平台够用，2K/4K 后期再上 |
| 帧率 | 60 FPS | 动作类必选 60，回合制可 30 |
| 码率 | 6000–12000 Kbps | 1080p60 建议 8000 起步 |

```bash
# 一个常见的 OBS 录制参数组合（1080p60）
编码器: NVENC H.264
码率控制: CQP
CQ Level: 20 (越小越清晰、文件越大)
关键帧间隔: 2s
```

格式那一栏值得多说一句。很多人图省事直接录 MP4，结果 OBS 崩一次，文件头没写完，整个文件打不开。MKV 是边录边写的容器，就算断电也只坏最后几秒。剪之前用 OBS 自带的「重新封装录像」转成 MP4，一分钟搞定。

### 音轨必须分开

游戏声音和麦克风录成两条独立音轨。剪辑时才能单独调音量、单独降噪。

OBS 里在「输出 → 音频」勾选多音轨，再到高级音频属性里把两个设备分配到不同轨道。

> [!WARNING]
> 把「系统声音 + 麦克风」混成一条轨，是新手翻车率最高的一个动作。背景音一旦盖过人声，后期基本救不回来 —— 不是我技术不行，是物理上就没剩下可用的信息。

## 素材整理：省下来的不是一分钟，是每次找素材的十分钟

剪辑最浪费时间的动作是「找」。一个固定命名规范，能用好几年。

推荐的文件夹结构：

```
游戏名/
├── 2026-09-08/
│   ├── raw/          # 原始录制，只读，永不改动
│   ├── clips/        # 剪出来的片段
│   └── audio/        # 音效、BGM
└── assets/           # 封面、字幕模板等可复用素材
```

命名用 `日期_游戏名_内容_序号`，例如 `20260908_minecraft_击杀集锦_01.mkv`。

`raw` 目录设成只读。这条不设，早晚有一次手滑把原素材覆盖掉，而且通常发生在赶稿的凌晨。

## 剪辑：把重复劳动交出去，把判断留下来

剪辑里最枯燥的三件事：掐头去尾、找高光、上字幕。这三件现在都能交出去。

1. **自动切条 / 找高光**。让工具按音量、击杀提示、弹幕峰值这些信号粗切，人只做精修。从几小时素材里一帧帧翻，和看几十个候选片段，效率差一个数量级。
2. **自动字幕**。语音转文字生成初稿，套上固定样式工程。字体字号这些别再每次手调。
3. **批量套模板**。封面、片头、字幕条、片尾关注动画全做成工程预设，一条龙套用。

> [!NOTE]
> 工具负责粗加工，人负责判断。值钱的是你的选点审美和节奏感 —— 这东西现在还没有工具能替。

具体的 AI 分工、提示词模板和工程化做法，我单独写了一篇：[《AI 辅助剪辑工作流》](https://du-19.top/posts/ai-video-editing-workflow/)。

## 导出：最后一步能毁掉前面全部

| 平台 | 分辨率/帧率 | 码率建议 | 其他 |
| :--- | :--- | :--- | :--- |
| B站 | 1080p60 | 6000–8000 Kbps | 上传后选「大会员」清晰度不影响原始质量 |
| 抖音 | 1080×1920 竖屏 | 8000 Kbps 左右 | 竖屏优先，标题和字幕放安全区 |
| 小红书 | 1080×1920 | 6000 Kbps 左右 | 首帧要抓人，封面比内容更决定点击 |

导出的通用原则：源素材什么规格，导出就别低于它。1080p60 的素材导出成 720p，画质损失会在平台二次压缩时被放大两遍。

## 分发：一条内容拆三次用

一条长视频可以拆成正片、三到五条竖屏切片、一篇图文，分别投到 B站、抖音、小红书。

同一份劳动，三次曝光。长期做下去，你积累的不只是播放量，还有一批认你 ID 的人 —— 那才是能带走的东西。
