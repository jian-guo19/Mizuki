## 这篇文章写给谁

如果你正在做（或想做）游戏实况、游戏二创、攻略短视频，却在「录出来糊、素材乱成一团、剪得又慢又累」这几个坑里打转，这篇能帮你把整条链路理顺。

先记住一个公式：**好的成片 = 录制的质量 × 素材的整理 × 剪辑的效率**。任何一环拖后腿，后面都会加倍还回来。

## 第一步：录制，先把地基打牢

录屏最怕的是「录的时候没感觉，剪的时候想重来」。所以录制阶段就定好标准，能省下后面大量返工。

### OBS 关键设置

| 设置项 | 建议值 | 说明 |
| :--- | :--- | :--- |
| 编码器 | NVENC / QSV / Apple 硬件编码 | 有独显优先用硬件编码，几乎不占 CPU |
| 视频格式 | MKV | 崩溃也不丢文件，剪前再转 MP4 |
| 基础分辨率 | 与显示器一致 | 避免强行缩放导致模糊 |
| 输出分辨率 | 1080p | 大多数平台够用，2K/4K 后期再上 |
| 帧率 | 60 FPS | 动作类必选 60，回合制可 30 |
| 码率 | 6000–12000 Kbps | 1080p60 建议 8000 起步 |

```bash
# 一个常见的 OBS 录制参数组合（1080p60）
编码器: NVENC H.264
码率控制: CQP
CQ Level: 20 (越小越清晰、文件越大)
关键帧间隔: 2s
```

### 录制音频要单独分轨

把「游戏声音」和「麦克风」录成两条独立的音轨，剪辑时才能分开调音量、单独降噪。OBS 里在「输出 → 音频」勾选多音轨，并在高级音频属性里把设备分配到不同轨道。

> [!WARNING]
> 录「系统声音 + 麦克风」混合成一条轨，是新手最常见的翻车点。一旦背景音太大盖过人声，后期几乎救不回来。

## 第二步：素材整理，一分钟也不白花

剪辑最浪费时间的是「找素材」。一个固定的命名规范，能让你长期受益。

推荐的文件夹结构：

```
游戏名/
├── 2026-09-08/
│   ├── raw/          # 原始录制，只读，永不改动
│   ├── clips/        # 剪出来的片段
│   └── audio/        # 音效、BGM
└── assets/           # 封面、字幕模板等可复用素材
```

命名建议：`日期_游戏名_内容_序号`，例如 `20260908_minecraft_击杀集锦_01.mkv`。

## 第三步：剪辑工作流，用 AI 把重复劳动交出去

剪辑里最枯燥的是「掐头去尾、找高光、上字幕」。这些现在都有 AI 工具可以分担：

1. **自动切条 / 找高光**：先让工具按音量、击杀提示、弹幕峰值等信号粗切，人再做精修，而不是从几小时素材里一点点翻。
2. **自动字幕**：语音转文字后生成字幕，再套上你固定的样式工程，避免每次手动调字体字号。
3. **批量套模板**：把封面、片头、字幕条、结尾关注动画做成「预设/工程」，一条龙套用。

> [!NOTE]
> AI 负责「粗加工」，人负责「判断」。真正值钱的是你的选点审美和节奏感，这部分别交给工具。

## 第四步：导出参数，别让最后一步毁掉画质

| 平台 | 分辨率/帧率 | 码率建议 | 其他 |
| :--- | :--- | :--- | :--- |
| B站 | 1080p60 | 6000–8000 Kbps | 上传后选「大会员」清晰度不影响原始质量 |
| 抖音 | 1080×1920 竖屏 | 8000 Kbps 左右 | 竖屏优先，标题和字幕放安全区 |
| 小红书 | 1080×1920 | 6000 Kbps 左右 | 首帧要抓人，封面比内容更决定点击 |

## 第五步：发布与分发，一条内容多次复用

一条长视频，可以拆成「正片 + 3–5 条竖屏切片 + 一篇图文」，分别发到 B站、抖音、小红书。让一次劳动产生多次曝光，也让你慢慢积累起自己的私域。
